# Расходы

Учёт личных расходов: сумма, категория, дата, необязательное описание. Итог за месяц, суммы по категориям, список с удалением и редактированием. Данные хранятся в SQLite и остаются после перезагрузки страницы.

## Функции

- Добавление, редактирование и удаление расходов с валидацией (сумма > 0, категория, дата)
- Итог за месяц и суммы по категориям, сравнение с прошлым месяцем, средний расход в день
- Переключение месяцев, график по месяцам за год
- Поле «на кого потратили» с итогами по получателям
- Поиск, фильтр по категории, экспорт месяца в CSV
- Бюджет на месяц (хранится в браузере)
- Swagger: `http://localhost:8001/docs`

## Стек

Next.js 16, React 19, TypeScript, HeroUI v3, Tailwind CSS 4 — фронтенд.
FastAPI, SQLAlchemy, Pydantic, SQLite — бэкенд. Без ИИ и внешних API.

## Структура

```
client/   Next.js, :3000, запросы /api/* проксируются на бэкенд
backend/  FastAPI, :8001, main.py — вся логика, expenses.db — данные
```

Эндпоинты: `GET/POST /api/products`, `GET/PUT/PATCH/DELETE /api/products/{id}`, `GET /api/products/summary?year&month`, `GET /api/products/export.csv?year&month`, `GET /api/categories`, `POST /api/seed`.

## Запуск

Нужны Python 3.9+ и Node.js 18+ (bun или npm).

```bash
./setup.sh   # зависимости
./start.sh   # бэкенд :8001 + фронтенд :3000
```

Или `make setup && make dev`, или `docker compose up --build`.

Вручную:

```bash
cd backend && python3 -m venv venv && ./venv/bin/pip install -r requirements.txt && ./venv/bin/uvicorn main:app --port 8001
cd client && bun install && bun run dev
```

Переменные: см. `.env.example`.

## Проверка

1. Открыть `http://localhost:3000`.
2. Добавить за один месяц: Еда 1500, Транспорт 600, Еда 900. Итог 3 000, еда 2 400, транспорт 600.
3. Удалить 900. Итог 2 100, еда 1 500.
4. Обновить страницу — данные на месте.
5. Сумма 0 или −50 отклоняется с сообщением, API отвечает 422.

Кнопка «Пример» загружает эти три записи. Автотест: `make test`.

## Ограничения

- Один пользователь, без авторизации
- Данные на сервере: без запущенного бэкенда фронт показывает ошибку
- Категории фиксированы
- Одна валюта
- Развёрнутой версии нет
