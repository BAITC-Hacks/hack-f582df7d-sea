# Backend: Учёт личных расходов студента (FastAPI)

Готовый REST API бэкенд с БД SQLite, валидацией данных, аналитикой трат и интерактивной документацией Swagger UI.

---

## Быстрый запуск

```bash
# 1. Активация виртуального окружения (уже настроено)
source venv/bin/activate

# 2. Запуск сервера
uvicorn main:app --reload --port 8001 --host 0.0.0.0
```

Сервер доступен по адресу: `http://localhost:8001`

---

## Интерактивная документация (Swagger UI)
👉 **[http://localhost:8001/docs](http://localhost:8001/docs)**  
(Альтернатива ReDoc: `http://localhost:8001/redoc`)

CORS полностью включен (`allow_origins=["*"]`) — фронтенд может слать запросы с любого порта (`localhost:3000`, `localhost:5173`, etc.).

## Сущность `products`

| Поле | Тип | Описание | Обязательное |
|---|---|---|---|
| `id` | `int` | Уникальный ID (автоинкремент) | Да (read-only) |
| `category` | `enum` | `Еда`, `Транспорт`, `Жилье`, `Развлечения`, `Образование`, `Здоровье`, `Одежда`, `Другое` | Да |
| `amount` | `float` | Сумма расхода (строго > 0) | Да |
| `date` | `string (date)` | Формат `YYYY-MM-DD` | Да |
| `description` | `string` | Описание расхода | Нет |

## Основные эндпоинты

### 1. CRUD по расходам (`/api/products`)
- `POST /api/products` — добавить расход
  ```json
  {
    "category": "Еда",
    "amount": 1500,
    "date": "2026-09-15",
    "description": "Обед в столовой"
  }
  ```
- `GET /api/products` — список всех трат (для графиков и истории)
  - Query params (опционально): `?year=2026&month=9&category=Еда`
  - Без параметров возвращает **все** расходы.
- `GET /api/products/{id}` — получить расход по ID
- `PUT /api/products/{id}` — обновить расход целиком
- `PATCH /api/products/{id}` — обновить отдельные поля расхода
- `DELETE /api/products/{id}` — удалить расход

### 2. Итоги и аналитика (`/api/products/summary`)
- `GET /api/products/summary?year=2026&month=9`
  Возвращает:
  - `total_amount`: общий итог расходов
  - `total_count`: количество трат
  - `category_breakdown`: разбивка по категориям с суммами и процентами (для круговой диаграммы)
  - `monthly_breakdown`: помесячные суммы за весь год (для столбчатого графика)
  - `items`: список трат за этот период

### 3. Вспомогательные
- `GET /api/categories` — список категорий для селекта на фронте
- `POST /api/seed` — заполнить базу контрольным примером (1500 еда, 600 транспорт, 900 еда = 3000)
